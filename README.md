# 花花 · Member's Mark 经典压花面巾

山姆会员优选（Member's Mark）经典压花面巾的单页宣传站。页面介绍软包吉祥物「花花」，嵌入 10 秒卡通宣传片，并列出五个产品特点：柔软如棉、经典压花、三层原生木浆、湿水不易破、无香亲肤。

这是一个静态演示页，不是销售或会员开通页面。

## 在线地址

https://albertsun6.github.io/huahua-promo/

## 本地预览

在仓库根目录启动任意静态文件服务，然后打开 `index.html`。例如：

```bash
python3 -m http.server 8080
```

视频与图片使用相对路径，放在 `assets/`：

- `assets/huahua_promo_10s.mp4`
- `assets/huahua_intro.jpg`
- `assets/huahua_end.jpg`
